## 🎯 项目愿景与目标

### 核心愿景

为 TypeDom 生态系统提供一套**完整、类型安全、高性能**的 SVG 图标解决方案，使开发者能够像使用普通组件一样使用 SVG 图标，同时保持完整的 TypeScript 类型支持和最优的打包体积。

### 三大核心目标

#### 1. SVG 组件化封装

**目标描述**: 将原始 SVG 图形封装为标准的 TypeDom 组件

**实现方式**:
- 每个 SVG 图标都是一个独立的 TypeScript 类
- 继承自 TypeDom 框架的 `TypeSvgSvg` 基类
- 支持与其他 TypeDom 组件（如 `Division`、`Text`）无缝组合
- 遵循统一的组件结构和生命周期

**示例代码**:
```typescript
import { Division, TypeRoot } from '@type-dom/framework';
import { TdAddSvg } from '@type-dom/svgs/common/add';

export class AppElement extends TypeRoot {
  className: 'AppElement';
  
  constructor() {
    super();
    this.className = 'AppElement';
    
    // SVG 图标作为普通组件使用
    this.addChild(
      new Division({
        children: [new TdAddSvg()]
      })
    );
  }
}
```

---

#### 2. 类型安全

**目标描述**: 利用 TypeScript 类型系统确保组件使用的安全性

**实现方式**:
- 所有组件都有完整的 TypeScript 类型定义
- 属性参数使用 `SvgProps` 接口约束
- 子节点类型明确定义为 `SvgPath[]`
- 编译时即可发现类型错误

**类型安全示例**:
```typescript
import { SvgProps, SvgPath, TypeSvgSvg, addAttrObj } from '@type-dom/framework';

export class TdAddSvg extends TypeSvgSvg {
  // 明确的类型声明
  className: 'TdAddSvg';
  override childNodes: SvgPath[];
  
  constructor(params: SvgProps = {}) {
    super(params);  // 参数类型安全
    
    this.className = 'TdAddSvg';
    addAttrObj(this, {
      name: 'TdAddSvg',
      viewBox: '0 0 1024 1024'
    });
    
    this.resetSize(24, 24);
    this.childNodes = [];
    
    const path0 = new SvgPath({ attrObj: { fill: 'currentColor' }});
    path0.setData('M512 42.666667...');
    this.addChild(path0);
  }
}
```

---

#### 3. 模块化设计

**目标描述**: 支持按需导入和 tree-shaking，优化打包体积

**实现方式**:
- 每个 SVG 组件都是独立的 ES Module
- 支持三种导入层级（推荐度递减）:
  1. ⭐⭐⭐ 单个组件导入：`import { TdAddSvg } from '@type-dom/svgs/common/add';`
  2. ⭐⭐ 分类索引导入：`import { TdAddSvg } from '@type-dom/svgs/common';`
  3. ⭐ 主入口导入：`import { TdAddSvg } from '@type-dom/svgs';` (不推荐)
- 构建工具配置支持 tree-shaking
- 使用 `unbundle: true` 保持源码目录结构

**打包体积对比**:
```
导入方式                  | 打包体积 | Tree-shaking
-----------------------|---------|-------------
单个组件导入            | ~2KB    | ✅ 优秀
分类索引导入 (Common)   | ~400KB  | ⚠️ 中等
主入口导入              | ~5MB    | ❌ 差
```

## 📦 核心功能特性

### 功能 1: SVG 组件化

**详细描述**: 将 SVG 图形封装为可复用的 TypeDom 组件

**关键特性**:
- ✅ 每个图标都是独立的类
- ✅ 支持构造函数参数
- ✅ 可设置自定义属性（尺寸、颜色等）
- ✅ 支持事件绑定（click、hover 等）
- ✅ 可与其他 TypeDom 组件组合

**使用场景**:
```typescript
// 基础使用
const icon = new TdAddSvg();

// 自定义尺寸和颜色
const customIcon = new TdAddSvg({
  width: 48,
  height: 48,
  fill: '#ff0000'
});

// 带事件的图标
const clickableIcon = new TdAddSvg({
  onClick: () => console.log('Icon clicked!')
});
```

---

### 功能 2: 分类管理

**四大图标库**:

| 分类名称 | 前缀 | 图标数量 | 风格特点 | 典型用途 |
|---------|------|---------|---------|---------|
| **Common** | `Td` | ~195 | 简洁通用 | 基础 UI 元素 |
| **Element Plus** | `El` | ~293 | Element 风格 | Vue/Element 项目 |
| **FluentUI** | `Fl` | ~5,255 | Microsoft 设计 | 企业级应用 |
| **Other** | `Td` | ~32 | 定制化 | 特殊需求 |

**Common 分类代表图标**:
- `TdAddSvg` - 加号图标
- `TdCloseSvg` - 关闭图标
- `TdUserSvg` - 用户图标
- `TdSearchSvg` - 搜索图标
- `Td404Svg` - 404 错误图标

**FluentUI 分类示例**:
- `FlAccessTimeFilledSvg` - 访问时间（填充风格）
- `FlAccessibilityCheckmarkRegularSvg` - 可访问性检查（常规风格）
- `FlAlertColorSvg` - 警告提示（彩色风格）

### 功能 3: 按需导入

**三种导入方式详解**:

#### ⭐⭐⭐ 方式 1: 单个组件导入（强烈推荐）

```typescript
// 只导入需要的组件，打包体积最小
import { TdAddSvg } from '@type-dom/svgs/common/add';
import { TdCloseSvg } from '@type-dom/svgs/common/close';

// 使用
const addIcon = new TdAddSvg();
const closeIcon = new TdCloseSvg();
```

**优点**:
- ✅ 打包体积最小（~2KB/组件）
- ✅ Tree-shaking 效果最佳
- ✅ 依赖关系清晰

---

#### ⭐⭐ 方式 2: 分类索引导入（可接受）

```typescript
// 从分类索引导入，会包含整个分类
import { TdAddSvg, TdCloseSvg } from '@type-dom/svgs/common';

// 使用
const icons = [new TdAddSvg(), new TdCloseSvg()];
```

**优点**:
- ✅ 导入语句简洁
- ✅ 适合同一分类使用多个图标

**缺点**:
- ⚠️ 会打包整个分类（Common ~400KB）

---

#### ⭐ 方式 3: 主入口导入（不推荐）

```typescript
// 从主入口导入，可能导入所有组件
import { TdAddSvg } from '@type-dom/svgs';

// 使用
const icon = new TdAddSvg();
```

**缺点**:
- ❌ 打包体积最大（~5MB）
- ❌ Tree-shaking 效果差
- ❌ 可能导入未使用的组件

---

### 功能 4: 标准化组件结构

**所有 SVG 组件遵循的统一结构**:

```typescript
// 标准模板
import { SvgProps, SvgPath, TypeSvgSvg, addAttrObj } from '@type-dom/framework';

export class TdIconNameSvg extends TypeSvgSvg {
  // 1. 类型声明
  className: 'TdIconNameSvg';
  override childNodes: SvgPath[];
  
  // 2. 构造函数
  constructor(params: SvgProps = {}) {
    super(params);
    
    // 2.1 设置类名
    this.className = 'TdIconNameSvg';
    
    // 2.2 添加基础属性
    addAttrObj(this, {
      name: 'TdIconNameSvg'
    });
    
    // 2.3 设置 viewBox（统一 1024x1024）
    addAttrObj(this, {
      viewBox: '0 0 1024 1024'
    });
    
    // 2.4 设置默认尺寸
    this.resetSize(24, 24);
    
    // 2.5 初始化子节点
    this.childNodes = [];
    
    // 2.6 创建路径（使用 currentColor）
    const path0 = new SvgPath({ 
      attrObj: { fill: 'currentColor' }
    });
    
    // 2.7 设置 SVG 路径数据
    path0.setData('M512 42.666667...');
    
    // 2.8 添加到 SVG
    this.addChild(path0);
  }
}
```

**结构优势**:
- ✅ 统一的开发体验
- ✅ 便于自动化转换
- ✅ 易于维护和扩展
- ✅ 类型安全保障

---

### 场景 2: 动态图形渲染

**用户需求**: 结合 TypeDom 的响应式机制，动态更新 SVG 内容

**解决方案**:
```typescript
class DynamicIcon extends Division {
  private isExpanded = false;
  
  constructor() {
    super();
    
    const icon = new TdArrowDownSvg({
      onClick: () => this.toggle(),
      style: {
        transition: 'transform 0.3s'
      }
    });
    
    this.addChild(icon);
  }
  
  toggle() {
    this.isExpanded = !this.isExpanded;
    // 通过 CSS 实现动画
    this.setStyle('transform', 
      this.isExpanded ? 'rotate(180deg)' : 'rotate(0deg)'
    );
  }
}
```
