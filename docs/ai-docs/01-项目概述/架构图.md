## 📊 架构层次详解

### 第一层：应用层 (Application Layer)

**职责**: 业务逻辑实现，使用 SVG 组件构建用户界面

**典型场景**:
```typescript
import { Division, TypeRoot, Text } from '@type-dom/framework';
import { TdAddSvg, TdCloseSvg } from '@type-dom/svgs/common';
import { FlSettingsColorSvg } from '@type-dom/svgs/fluentui';

export class AppElement extends TypeRoot {
  className: 'AppElement';
  
  constructor() {
    super();
    this.className = 'AppElement';
    
    // 标题栏
    const header = new Division({
      attrObj: { class: 'header' },
      children: [
        new Text({ text: 'My Application' }),
        new FlSettingsColorSvg({ width: 24, height: 24 })
      ]
    });
    
    // 操作按钮
    const actionBtn = new Division({
      attrObj: { class: 'btn', onClick: () => this.handleAdd() },
      children: [
        new TdAddSvg({ width: 16, height: 16 }),
        new Text({ text: 'Add Item' })
      ]
    });
    
    this.addChild(header, actionBtn);
  }
  
  handleAdd() {
    console.log('Add button clicked');
  }
}
```

### 第二层：组件层 (@type-dom/svgs)

**职责**: 提供各类 SVG 图标组件，按风格分类管理

#### 四大分类详解

| 分类 | 前缀 | 数量 | 风格特点 | 典型用途 | 代表组件 |
|------|------|------|---------|---------|----------|
| **Common** | `Td` | ~195 | 简洁通用 | 基础 UI 元素 | TdAddSvg, TdCloseSvg, TdUserSvg |
| **Element Plus** | `El` | ~293 | Element 风格 | Vue/Element 项目 | ElArrowDownSvg, ElCheckSvg |
| **FluentUI** | `Fl` | ~5,255 | Microsoft 设计 | 企业级应用 | FlFolderFilledSvg, FlAlertColorSvg |
| **Other** | `Td` | ~32 | 定制化 | 特殊需求 | TdCompanyLogoSvg |

#### Common 分类示例

```typescript
// src/lib/common/add.ts
import { SvgProps, SvgPath, TypeSvgSvg, addAttrObj } from '@type-dom/framework';

export class TdAddSvg extends TypeSvgSvg {
  className: 'TdAddSvg';
  override childNodes: SvgPath[];
  
  constructor(params: SvgProps = {}) {
    super(params);
    this.className = 'TdAddSvg';
    addAttrObj(this, { name: 'TdAddSvg', viewBox: '0 0 1024 1024' });
    this.resetSize(24, 24);
    this.childNodes = [];
    const path0 = new SvgPath({ attrObj: { fill: 'currentColor' }});
    path0.setData('M512 42.666667...');
    this.addChild(path0);
  }
}
```

### 第三层：框架层 (@type-dom/framework)

**职责**: 提供类型安全的组件开发基础

#### 核心基类体系

```
TypeElement (抽象基类)
│
├─ 属性:
│  ├─ className: string        // 类名标识
│  ├─ parent: TypeElement|null // 父节点引用
│  ├─ childNodes: TypeElement[] // 子节点数组
│  ├─ attrObj: Record<string, any> // HTML 属性
│  └─ styleObj: Record<string, any> // CSS 样式
│
├─ 方法:
│  ├─ addChild(...children: TypeElement[]): void
│  ├─ removeChild(child: TypeElement): void
│  ├─ setAttr(key: string, value: any): void
│  ├─ setStyle(key: string, value: string): void
│  └─ mount(container: HTMLElement): void
│
↓
TypeSvg (SVG 抽象基类)
│
├─ SVG 特定属性和方法:
│  ├─ viewBox: string
│  ├─ preserveAspectRatio: string
│  └─ resetSize(width: number, height: number): void
│
↓
TypeSvgSvg (<svg> 元素基类)
│
└─ 具体 SVG 组件类:
   ├─ TdAddSvg (Common)
   ├─ ElArrowDownSvg (Element Plus)
   └─ FlAccessTimeFilledSvg (FluentUI)
```

#### 类型定义体系

```typescript
// SvgProps 接口 - SVG 组件属性
interface SvgProps {
  // 基础属性
  width?: number | string;
  height?: number | string;
  viewBox?: string;
  
  // 样式属性
  fill?: string;
  stroke?: string;
  strokeWidth?: number | string;
  
  // 事件处理
  onClick?: (event: MouseEvent) => void;
  onMouseEnter?: (event: MouseEvent) => void;
  onMouseLeave?: (event: MouseEvent) => void;
  
  // 其他 SVG 属性
  preserveAspectRatio?: string;
  xmlns?: string;
}

// TypeProps 接口 - 通用组件属性
interface TypeProps {
  className?: string;
  id?: string;
  attrObj?: Record<string, any>;
  styleObj?: Record<string, any>;
  children?: TypeElement[];
  events?: Record<string, Function>;
}
```

## 🎯 架构设计原则

### 1. 单一职责原则 (SRP)

每个类只负责一个职责:
- `TypeSvgSvg`: 负责 SVG 容器
- `SvgPath`: 负责 SVG 路径
- `TdAddSvg`: 负责具体的加号图标

### 2. 开闭原则 (OCP)

对扩展开放，对修改封闭:
```typescript
// ✅ 扩展示例：添加新图标
class TdNewIconSvg extends TypeSvgSvg {
  // 新图标实现
}

// ❌ 不要修改现有类
// class TdAddSvg { ... 修改代码 ... }
```

### 3. 依赖倒置原则 (DIP)

依赖抽象而非具体实现:
```typescript
// ✅ 正确：依赖抽象基类
function renderIcon(icon: TypeSvgSvg) {
  icon.mount(container);
}

// ❌ 错误：依赖具体类
function renderIcon(icon: TdAddSvg) {
  // ...
}
```

### 4. 类型安全原则

所有公开 API 都有明确的类型定义:
```typescript
// ✅ 完整类型定义
export class TdAddSvg extends TypeSvgSvg {
  className: 'TdAddSvg';  // 字符串字面量类型
  override childNodes: SvgPath[];  // 明确的数组类型
  
  constructor(params: SvgProps = {}) {  // 参数类型约束
    // ...
  }
}
```

## 📝 总结

@type-dom/svgs 的架构设计遵循以下核心理念:

1. **分层清晰**: 应用层 → 组件层 → 框架层 → 运行时
2. **类型安全**: TypeScript 全栈类型覆盖
3. **模块化**: 每个组件独立，支持按需导入
4. **可扩展**: 遵循 SOLID 原则，易于添加新图标
5. **性能优化**: Tree-shaking 友好，打包体积小
