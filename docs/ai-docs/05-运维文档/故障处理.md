### 故障 1: NPM 包无法安装

**故障现象**:
```bash
npm install @type-dom/svgs
npm ERR! code E404
npm ERR! 404 Not Found - GET https://registry.npmjs.org/@type-dom%2fsvgs - Not found
```

**影响范围**: 
- ❌ 所有用户无法安装包
- ❌ CI/CD流程中断
- ❌ 项目无法部署

**排查步骤**:

```bash
# Step 1: 验证 NPM 包是否存在
curl https://www.npmjs.com/package/@type-dom/svgs

# Step 2: 检查 NPM Registry 状态
npm ping
# 应该返回：pong

# Step 3: 查看包的详细信息
npm view @type-dom/svgs --json

# Step 4: 检查本地网络
ping registry.npmjs.org
```

**可能原因**:

1. **NPM Registry 故障** (最常见)
   ```bash
   # 检查 NPM 状态页面
   https://status.npmjs.org/
   
   # 如果是全局故障，等待修复
   ```

2. **包被误删除**
   ```bash
   # 联系 NPM 支持
   support@npmjs.com
   
   # 提供信息：
   # - 包名：@type-dom/svgs
   # - 最后版本：0.4.0
   # - 删除时间（如果知道）
   ```

3. **权限问题**
   ```bash
   # 验证登录状态
   npm whoami
   
   # 如果未登录
   npm login
   
   # 检查包的访问权限
   npm access list packages
   ```

**解决方案**:

**方案 A: 重新发布**
```bash
# 1. 确认本地有构建产物
ls dist/

# 2. 重新发布
npm publish --access public

# 3. 验证发布成功
npm view @type-dom/svgs version
```

**方案 B: 使用 CDN 临时替代**
```typescript
// 在项目中临时使用 unpkg CDN
import { TdAddSvg } from 'https://unpkg.com/@type-dom/svgs@0.4.0/dist/index.mjs';

// 或者在 HTML 中直接使用
<script type="module">
  import { TdAddSvg } from 'https://unpkg.com/@type-dom/svgs@0.4.0';
</script>
```

**预防措施**:
- ✅ 配置多个 NPM Registry 镜像
- ✅ 锁定依赖版本（package-lock.json）
- ✅ 使用私有 NPM 镜像（如 Verdaccio）

```bash
if [ $ERROR_COUNT -gt 0 ]; then
```

### 故障 3: TypeScript 类型错误爆发

**故障现象**:
```bash
npm run typecheck

Found 127 errors in 45 files.
Errors  Files
     5  src/lib/common/TdAddSvg.ts:15
     3  src/lib/common/TdCloseSvg.ts:12
    ...
```

**影响**:
- 🔴 无法通过 CI 检查
- 🔴 类型安全失效
- 🔴 IDE 提示混乱

**批量修复策略**:

**Step 1: 分类错误**

```bash
# 统计各类错误的数量
npm run typecheck 2>&1 | grep "error TS" | \
  sed 's/.*error TS\([0-9]*\).*/TS\1/' | \
  sort | uniq -c | sort -rn

# 输出示例：
  45 TS2416  # Property incompatible with base class
  32 TS2304  # Cannot find name
  25 TS2307  # Cannot find module
  15 TS2322  # Type not assignable
```

**Step 2: 优先修复高频错误**

**TS2416 - 继承属性不兼容**
```typescript
// 通用修复模式
export class XxxSvg extends TypeSvgSvg {
  // ❌ 错误
  childNodes: SvgPath[];
  
  // ✅ 正确
  override childNodes: SvgPath[];
  
  // ❌ 错误
  resetSize(w: number, h: number) { }
  
  // ✅ 正确
  override resetSize(w: number, h: number): void { }
}
```

**批量修复脚本**:
```bash
#!/bin/bash
# scripts/fix-ts2416.sh

echo "Fixing TS2416 errors..."

# 查找所有 SVG 文件
find src/lib -name "*.ts" -type f | while read file; do
  # 检查是否有 childNodes 但没有 override
  if grep -q "childNodes:" "$file" && ! grep -q "override childNodes:" "$file"; then
    echo "Fixing: $file"
    sed -i '' 's/childNodes:/override childNodes:/g' "$file"
  fi
  
  # 检查是否有 resetSize 但没有 override
  if grep -q "resetSize(" "$file" && ! grep -q "override resetSize(" "$file"; then
    echo "Fixing: $file"
    sed -i '' 's/resetSize(/override resetSize(/g' "$file"
  fi
done

echo "Running type check to verify..."
npm run typecheck
```

**TS2307 - 模块未找到**

```typescript
// 统一修复导入路径
// ❌ 错误：相对路径容易出错
```

```typescript
// 用户报告
```

```typescript
const svg = new TdAddSvg({ width: 24, height: 24 });
console.log('className:', svg.className);
console.log('viewBox:', svg.viewBox);
```

```typescript
svg.childNodes.forEach((path, index) => {

  console.log('  d:', path.d);

// 验证 path data 有效性
function isValidPathData(d: string): boolean {

  return /[MLHVCSQTAZ]/i.test(d);
```

**Step 3: 挂载到 DOM**
```typescript
const container = document.createElement('div');
svg.mount(container);

// 应该有 <svg> 元素
const svgElement = container.querySelector('svg');
```

**常见问题**:

```typescript
// ❌ 错误：viewBox 未设置或格式错误
```

### 故障 6: Tree-shaking 失效

**故障现象**:
```bash
# 打包后体积过大
Bundle size: 2.3 MB  # 应该只有 ~500KB

# 分析发现所有图标都被打包了
```

**诊断工具**:

```bash
# 使用 rollup-plugin-visualizer
npm install --save-dev rollup-plugin-visualizer

# vite.config.ts
import { visualizer } from 'rollup-plugin-visualizer';

export default {
  plugins: [
    visualizer({
      filename: 'dist/stats.html',
      open: true
    })
  ]
};

# 然后运行构建
npm run build

# 打开 stats.html 查看打包分析
open dist/stats.html
```

**常见原因与修复**:

**原因 1: 全量导入**
```typescript
// ❌ 错误：全量导入
import * as AllIcons from '@type-dom/svgs';
// 这样会导入所有 5000+ 个图标

// ✅ 正确：按需导入
import { TdAddSvg } from '@type-dom/svgs';
import { ElArrowDownSvg } from '@type-dom/svgs';

// 或者动态导入
const icon = await import('@type-dom/svgs').then(
  m => m.TdAddSvg
);
```

**原因 2: CommonJS 格式**
```javascript
// ❌ 错误：CommonJS 不支持 tree-shaking
const { TdAddSvg } = require('@type-dom/svgs');

// ✅ 正确：使用 ESM
import { TdAddSvg } from '@type-dom/svgs';
```

**原因 3: Side Effects 未声明**
```json
// package.json
{
  "sideEffects": false,  // ← 声明无副作用
  "exports": {
    ".": {
      "import": "./dist/index.mjs",
      "require": "./dist/index.cjs"
    }
  }
}
```
