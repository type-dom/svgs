## 📋 命名约定 (Naming Conventions)

### 组件类命名规则

**基本规则**: `{Prefix}{IconName}{Style}Svg`

```typescript
// ✅ 正确的命名示例
export class TdAddSvg extends TypeSvgSvg { }
export class FlAccessTimeFilledSvg extends TypeSvgSvg { }
export class ElArrowDownRegularSvg extends TypeSvgSvg { }

// ❌ 错误的命名示例
export class AddSvgComponent { }           // 缺少前缀和后缀
export class tdAddSvg { }                  // 首字母应大写
export class ADD_SVG { }                   // 不应使用全大写
```

#### 前缀规范

| 分类 | 前缀 | 含义 | 示例 | 数量 |
|------|------|------|------|------|
| **Common** | `Td` | TypeDom 通用图标 | `TdAddSvg`, `TdUserSvg` | ~195 |
| **Element Plus** | `El` | Element Plus 风格 | `ElArrowDownSvg`, `ElCheckSvg` | ~293 |
| **FluentUI** | `Fl` | Microsoft Fluent UI | `FlFolderFilledSvg`, `FlAlertColorSvg` | ~5,255 |
| **Other** | `Td` | 自定义图标 | `TdCompanyLogoSvg` | ~32 |

#### 图标命名规则

**Common 分类**: 使用简洁的英文名称

```typescript
// ✅ 推荐
TdAddSvg          // 加号
TdCloseSvg        // 关闭
TdUserSvg         // 用户
TdSearchSvg       // 搜索
TdSettingsSvg     // 设置

// ⚠️ 避免
TdAdditionSvg     // 过于冗长
TdPlusIconSvg     // 重复（已有 Svg 后缀）
```

**FluentUI 分类**: 遵循 Microsoft 命名规范

```typescript
// 格式：{Name}{Style}Svg
FlAccessTimeFilledSvg      // 填充风格
FlAccessibilityRegularSvg  // 常规风格
FlAlertColorSvg            // 彩色风格
FlArrowClockwiseDashedSvg  // 虚线箭头
```

### 文件命名规则

**基本规则**: 小写字母 + 连字符（kebab-case）

```typescript
// ✅ 正确的文件命名
add.ts                    // Common 分类
access_time_filled.ts     // FluentUI 分类
arrow-down.ts             // 带连字符
company-logo.ts           // 自定义图标

// ❌ 错误的文件命名
Add.ts                    // 首字母大写
addSvg.ts                 // camelCase
ADD.TS                    // 全大写
add_icon.ts               // 下划线分隔
```

#### 文件名与类名映射

```typescript
// 文件：src/lib/common/add.ts
export class TdAddSvg extends TypeSvgSvg { }

// 文件：src/lib/fluentui/access_time_filled.ts
export class FlAccessTimeFilledSvg extends TypeSvgSvg { }

// 文件：src/lib/element-plus/arrow-down.ts
export class ElArrowDownSvg extends TypeSvgSvg { }
```

### 变量和函数命名

**局部变量**: 使用 camelCase（小驼峰）

```typescript
// ✅ 正确
const pathData = 'M512 42.666667...';
const iconWidth = 24;
const createPath = () => new SvgPath();

// ❌ 错误
const PathData = '...';     // 首字母不应大写
const ICON_WIDTH = 24;      // 非常量不应全大写
```

**常量**: 使用 UPPER_CASE（全大写 + 下划线）

```typescript
// ✅ 真正的常量
const DEFAULT_SIZE = 24;
const VIEWBOX_SIZE = '0 0 1024 1024';

// ⚠️ 注意：TypeScript 中 const 不一定是常量
const config = { size: 24 };  // 这是对象，仍用 camelCase
```

## 📝 代码风格 (Code Style)

### 类结构顺序

**标准顺序**:

```typescript
// 1. 导入语句
import { SvgProps, SvgPath, TypeSvgSvg, addAttrObj } from '@type-dom/framework';

// 2. 类定义
export class TdAddSvg extends TypeSvgSvg {
  // 3. 类型声明（public 属性）
  className: 'TdAddSvg';
  override childNodes: SvgPath[];
  
  // 4. 构造函数
  constructor(params: SvgProps = {}) {
    // 4.1 调用父类构造函数
    super(params);
    
    // 4.2 设置类名
    this.className = 'TdAddSvg';
    
    // 4.3 添加基础属性
    addAttrObj(this, {
      name: 'TdAddSvg',
      viewBox: '0 0 1024 1024'
    });
    
    // 4.4 设置默认尺寸
    this.resetSize(24, 24);
    
    // 4.5 初始化子节点
    this.childNodes = [];
    
    // 4.6 创建路径
    const path0 = new SvgPath({ attrObj: { fill: 'currentColor' }});
    path0.setData('M512 42.666667...');
    
    // 4.7 添加到 SVG
    this.addChild(path0);
  }
}
```

### 导入语句规范

**分组顺序**:

```typescript
// 第一组：框架导入
import { SvgProps, SvgPath, TypeSvgSvg, addAttrObj } from '@type-dom/framework';

// 第二组：同项目其他模块（如有）
// import { utils } from '../utils';

// 第三组：第三方库（如有）
// import { someLib } from 'some-lib';

// 空行分隔
```

**导入方式**:

```typescript
// ✅ 推荐：按需导入
import { TdAddSvg } from '@type-dom/svgs/common/add';

// ⚠️ 可接受：分类索引导入（会打包整个分类）
import { TdAddSvg, TdCloseSvg } from '@type-dom/svgs/common';

// ❌ 不推荐：主入口导入
import { TdAddSvg } from '@type-dom/svgs';
```

### 缩进和格式化

**基本规则**:

```typescript
// 缩进：2 个空格（不使用 Tab）
export class TdAddSvg extends TypeSvgSvg {
  className: 'TdAddSvg';  // 2 个空格缩进
  
  constructor() {
    super();
    this.className = 'TdAddSvg';  // 4 个空格缩进
  }
}

// 空行：逻辑块之间空一行
export class TdAddSvg extends TypeSvgSvg {
  className: 'TdAddSvg';
  override childNodes: SvgPath[];
  
  constructor(params: SvgProps = {}) {
    super(params);
    this.className = 'TdAddSvg';
    
    addAttrObj(this, { name: 'TdAddSvg' });
    
    this.resetSize(24, 24);
    
    this.childNodes = [];
    const path0 = new SvgPath({ attrObj: { fill: 'currentColor' }});
    path0.setData('...');
    
    this.addChild(path0);
  }
}

// 行宽：建议不超过 100 字符
const longPathData = 'M512 42.666667c259.2 0 469.333333...';  // 可以分多行
```

**对象格式化**:

```typescript
// ✅ 推荐：多行格式（属性较多时）
addAttrObj(this, {
  name: 'TdAddSvg',
  viewBox: '0 0 1024 1024',
  title: 'Add Icon'
});

// ✅ 可接受：单行格式（属性较少时）
addAttrObj(this, { name: 'TdAddSvg', viewBox: '0 0 1024 1024' });

// ❌ 避免：混合格式
addAttrObj(this, { name: 'TdAddSvg',
  viewBox: '0 0 1024 1024' });
```

---

### 字符串引号

**统一使用单引号**:

```typescript
// ✅ 正确
this.className = 'TdAddSvg';
path0.setData('M512 42.666667...');

// ❌ 错误
this.className = "TdAddSvg";
```

## 💬 注释规范 (Comments)

### 文件头部注释

**不强制要求，保持简洁**:

```typescript
// ✅ 可选：简单的文件说明
// 加号图标组件
import { ... } from '@type-dom/framework';

// ❌ 避免：过度详细的头部注释
/**
 * @file add.ts
 * @author Your Name
 * @date 2026-03-17
 * @version 1.0.0
 * @description 这是一个加号图标...
 */
```

---

### 复杂逻辑注释

**使用单行注释**:

```typescript
// ✅ 推荐：解释意图
// 用户头像轮廓
const headPath = new SvgPath({ attrObj: { fill: 'currentColor' }});
headPath.setData('M...');

// 身体部分
const bodyPath = new SvgPath({ attrObj: { fill: 'currentColor' }});
bodyPath.setData('M...');

// ❌ 避免：重复代码做什么
const headPath = new SvgPath();  // 创建一个路径
headPath.setData('...');         // 设置路径数据
```

---

### TODO 注释

**标记待办事项**:

```typescript
// TODO: 优化路径数据，减少点数
const complexPath = 'M...';

// FIXME: 在某些浏览器上颜色渲染有问题
const fillColor = 'currentColor';

// XXX: 性能警告：这个图标有 10 个路径，考虑简化
const performanceHeavyIcon = '...';
```

## 🎨 最佳实践 (Best Practices)

### 1. 使用 currentColor

**让图标继承父元素颜色**:

```typescript
// ✅ 推荐
const path0 = new SvgPath({ attrObj: { fill: 'currentColor' }});

// ❌ 避免：硬编码颜色
const path0 = new SvgPath({ attrObj: { fill: '#333333' }});
```

**好处**:
- ✅ 主题友好：自动适配亮色/暗色主题
- ✅ 样式统一：继承父元素颜色
- ✅ 易于维护：修改一处即可

---

### 2. 统一的 viewBox

**所有图标使用 1024x1024 坐标系统**:

```typescript
// ✅ 标准做法
addAttrObj(this, { viewBox: '0 0 1024 1024' });

// ❌ 避免：不同的 viewBox
addAttrObj(this, { viewBox: '0 0 24 24' });
addAttrObj(this, { viewBox: '0 0 512 512' });
```

**好处**:
- ✅ 标准化：所有图标统一规格
- ✅ 易缩放：基于 1024 等比缩放
- ✅ 易维护：统一的坐标系统

---

### 3. 默认尺寸设置

**推荐默认 24x24 像素**:

```typescript
// ✅ 标准做法
this.resetSize(24, 24);

// ⚠️ 特殊情况可使用其他尺寸
this.resetSize(16, 16);  // 小图标
this.resetSize(32, 32);  // 大图标
this.resetSize(48, 48);  // 装饰图标
```

---

### 4. 路径优化

**减少路径点数，优化性能**:

```typescript
// ✅ 优化后的路径（较少的点）
const optimizedPath = 'M512 42.666667c259.2 0...';

// ❌ 避免：过多的点
const tooManyPoints = 'M512 42.666667L513 43L514 43.333...';
```

**使用工具简化路径**:

```bash
# 使用 trans-svgs 脚本自动优化
npm run common-svgs
```

---

### 5. 类型安全

**避免使用 any 类型**:

```typescript
// ✅ 正确：明确的类型
constructor(params: SvgProps = {}) {
  const pathData: string = 'M...';
  const width: number = 24;
}

// ❌ 错误：使用 any
constructor(params: any) {
  const pathData: any = 'M...';
}
```

## 🔍 常见错误与解决方案

### 错误 1: 类名与文件名不匹配

```typescript
// ❌ 错误
// 文件：add.ts
export class AddSvg extends TypeSvgSvg { }  // 缺少前缀

// ✅ 正确
// 文件：add.ts
export class TdAddSvg extends TypeSvgSvg { }
```

---

### 错误 2: 忘记设置 className

```typescript
// ❌ 错误
export class TdAddSvg extends TypeSvgSvg {
  className: 'TdAddSvg';
  
  constructor() {
    super();
    // 忘记设置 this.className
  }
}

// ✅ 正确
export class TdAddSvg extends TypeSvgSvg {
  className: 'TdAddSvg';
  
  constructor() {
    super();
    this.className = 'TdAddSvg';  // 必须设置
  }
}
```

---

### 错误 3: viewBox 格式错误

```typescript
// ❌ 错误
addAttrObj(this, { viewBox: '0,0,1024,1024' });  // 逗号分隔
addAttrObj(this, { viewBox: 1024 });             // 单个数字

// ✅ 正确
addAttrObj(this, { viewBox: '0 0 1024 1024' });  // 空格分隔
```

---

### 错误 4: 路径未初始化

```typescript
// ❌ 错误
export class TdAddSvg extends TypeSvgSvg {
  override childNodes: SvgPath[];
  
  constructor() {
    super();
    this.childNodes.push(new SvgPath());  // childNodes 未初始化
  }
}

// ✅ 正确
export class TdAddSvg extends TypeSvgSvg {
  override childNodes: SvgPath[];
  
  constructor() {
    super();
    this.childNodes = [];  // 先初始化
    const path0 = new SvgPath();
    this.childNodes.push(path0);
  }
}
```
