# 命名约定

**最后更新**: 2026-03-17  
**版本**: v0.4.0

---

## 📋 组件命名规则 (Component Naming)

### 基本格式

```
{Prefix}{IconName}{Style}Svg
```

**组成部分**:

- **Prefix**: 分类前缀（Td / El / Fl）
- **IconName**: 图标名称（PascalCase）
- **Style**: 风格修饰（Filled / Regular / Color 等，可选）
- **Svg**: 固定后缀

---

### 前缀规范详解

| 分类             | 前缀 | 全称    | 说明                 | 图标数量 |
| ---------------- | ---- | ------- | -------------------- | -------- |
| **Common**       | `Td` | TypeDom | TypeDom 通用图标库   | ~195     |
| **Element Plus** | `El` | Element | Element Plus UI 风格 | ~293     |
| **FluentUI**     | `Fl` | Fluent  | Microsoft Fluent UI  | ~5,255   |
| **Other**        | `Td` | TypeDom | 其他自定义图标       | ~32      |

#### Common 分类命名特点

```typescript
// ✅ 简洁明了
TdAddSvg; // 加号
TdCloseSvg; // 关闭
TdUserSvg; // 用户
TdSearchSvg; // 搜索
TdSettingsSvg; // 设置

// ⚠️ 避免过于复杂
TdAdditionSymbolSvg; // 过于冗长
TdPlusSignIconSvg; // 重复（已有 Svg 后缀）
```

#### FluentUI 分类命名特点

```typescript
// 遵循 Microsoft 官方命名规范
// 格式：Fl{Name}{Style}Svg

// Style 说明:
// - Filled: 填充风格（实心）
// - Regular: 常规风格（空心/线条）
// - Color: 彩色版本
// - Dashed: 虚线
// - Sync: 同步动画版本

FlAccessTimeFilledSvg; // 访问时间（填充）
FlAccessibilityRegularSvg; // 可访问性（常规）
FlAlertColorSvg; // 警告（彩色）
FlArrowClockwiseDashedSvg; // 顺时针箭头（虚线）
```

## 📁 文件命名规范 (File Naming)

### Common 分类文件命名

**格式**: `{icon-name}.ts`（kebab-case）

```typescript
// ✅ 正确示例
add.ts                    → TdAddSvg
close-revision.ts         → TdCloseRevisionSvg
user.ts                   → TdUserSvg
search.ts                 → TdSearchSvg
company-logo.ts           → TdCompanyLogoSvg

// ❌ 错误示例
Add.ts                    // 首字母大写
addSvg.ts                 // camelCase
ADD.TS                    // 全大写
add_icon.ts               // 下划线分隔
```

---

### Element Plus 分类文件命名

**格式**: `{icon-name}.ts`（kebab-case）

```typescript
// ✅ 正确示例
arrow-down.ts             → ElArrowDownSvg
caret-left.ts             → ElCaretLeftSvg
check.ts                  → ElCheckSvg
info.ts                   → ElInfoSvg
warning-filled.ts         → ElWarningFilledSvg

// ❌ 错误示例
ArrowDown.ts              // PascalCase
arrow_down.ts             // snake_case
```

---

### FluentUI 分类文件命名

**格式**: `{icon_name}_{style}.ts`（snake_case + 下划线分隔风格）

```typescript
// ✅ 正确示例
access_time_filled.ts     → FlAccessTimeFilledSvg
add_circle_regular.ts     → FlAddCircleRegularSvg
alert_color.ts            → FlAlertColorSvg
arrow_clockwise_dashed.ts → FlArrowClockwiseDashedSvg

// ❌ 错误示例
access-time-filled.ts     // kebab-case（不适用）
AccessTimeFilled.ts       // PascalCase
```

## 🔄 文件名到类名的转换规则

### 自动转换逻辑

使用 `trans-svgs/utils.mjs` 中的 `toHump` 函数:

```javascript
// 文件名 → 类名映射
'add'                    → 'Add'                    → TdAddSvg
'close-revision'         → 'CloseRevision'          → TdCloseRevisionSvg
'user-profile'            → 'UserProfile'            → TdUserProfileSvg
'A+'                     → 'APlus'                  → TdAPlusSvg
'access_time_filled'     → 'AccessTimeFilled'       → FlAccessTimeFilledSvg
'add_circle_regular'     → 'AddCircleRegular'       → FlAddCircleRegularSvg
```

---

### 特殊字符处理

#### 连字符 `-` 的处理

```javascript
// 标准情况：连字符转大写
'arrow-down'       → 'ArrowDown'
'search-history'   → 'SearchHistory'

// 特殊情况：以连字符结尾
'close-'           → 'Closeminus'    → TdCloseMinusSvg
'add-'             → 'Addminus'      → TdAddMinusSvg
```

#### 加号 `+` 的处理

```javascript
// 加号转为 Plus
'A+'                → 'APlus'         → TdAPlusSvg
'plus-1'            → 'Plus1'         → TdPlus1Svg
```

#### 数字的处理

```javascript
// 数字保持不变
'icon-3d'           → 'Icon3d'        → TdIcon3dSvg
'level-1'           → 'Level1'        → TdLevel1Svg
```

## 💡 变量和方法命名 (Variables & Methods)

### 局部变量命名

**规则**: 小驼峰 (camelCase)

```typescript
// ✅ 正确示例
const pathData = "M512 42.666667...";
const svgElement = new TdAddSvg();
let currentIndex = 0;
const iconWidth = 24;
const createPath = () => new SvgPath();

// ❌ 错误示例
const PathData = "..."; // 首字母大写（这是 PascalCase）
const PATH_DATA = "..."; // 全大写（这是常量命名）
const path_data = "..."; // 下划线分隔（snake_case）
```

---

### 常量命名

**规则**: 全大写 + 下划线分隔 (UPPER_CASE)

```typescript
// ✅ 真正的常量
const DEFAULT_SIZE = 24;
const VIEW_BOX = "0 0 1024 1024";
const MAX_PATH_LENGTH = 1000;
const SVG_NAMESPACE = "http://www.w3.org/2000/svg";

// ⚠️ 注意：const 声明的不一定是常量
const config = { size: 24 }; // 这是对象引用，仍用 camelCase
const ICON_COLORS = ["#ff0000"]; // 数组引用，可以用大写
```

---

### 方法命名

**规则**: 小驼峰 (camelCase)，动词开头

```typescript
// ✅ 正确示例
resetSize(width: number, height: number) { }
setData(pathData: string) { }
addChild(child: SvgPath) { }
removeChild(index: number) { }
getPathData() { }

// 动词 + 名词结构
createPathElement() { }
updateViewBox() { }
calculateAspectRatio() { }

// ❌ 错误示例
ResetSize() { }      // 首字母大写
reset_size() { }     // 下划线分隔
sizeReset() { }      // 名词在前（不推荐）
```

---

### 布尔值命名

**规则**: 使用 is/has/can/should 等前缀

```typescript
// ✅ 清晰的布尔值命名
const isEmpty = true;
const hasChildren = false;
const canRender = true;
const shouldUpdate = false;
const isVisible = true;

// ❌ 避免
const empty = true; // 不明确
const children = false; // 类型不清晰
```

## 🎨 命名最佳实践

### 1. 语义化命名

```typescript
// ✅ 语义清晰
const primaryColor = "#333";
const secondaryColor = "#666";
const disabledOpacity = 0.5;

// ❌ 语义模糊
const color1 = "#333";
const color2 = "#666";
const opacity = 0.5;
```

---

### 2. 避免缩写（除非通用）

```typescript
// ✅ 使用完整单词
const backgroundColor = "#fff";
const strokeWidth = 2;
const viewBox = "0 0 1024 1024";

// ⚠️ 可接受的通用缩写
const svg = "<svg>"; // SVG 是标准缩写
const html = "<div>"; // HTML 是标准缩写
const url = "https://..."; // URL 是标准缩写

// ❌ 避免自创缩写
const bgc = "#fff"; // 不清晰
const sw = 2; // 不清晰
const vb = "0 0 1024 1024"; // 不清晰
```

---

### 3. 保持一致性

```typescript
// ✅ 同一项目中保持一致
const iconSize = 24;
const iconColor = "#333";
const iconOpacity = 0.8;

// ❌ 混用不同风格
const iconSize = 24;
const IconColor = "#333"; // 突然 PascalCase
const ICON_OPACITY = 0.8; // 突然 UPPER_CASE
```

---

### 4. 区分复数形式

```typescript
// ✅ 明确单复数
const child = new SvgPath(); // 单个
const children = [path1, path2]; // 多个

const icon = new TdAddSvg(); // 单个图标
const icons = [icon1, icon2]; // 多个图标

// ❌ 混淆单复数
const child = [path1, path2]; // 名为 child 却是数组
const children = new SvgPath(); // 名为 children 却是单个
```

## 🔍 常见命名错误

### 错误 1: 前缀缺失

```typescript
// ❌ 错误
export class AddSvg extends TypeSvgSvg {}

// ✅ 正确
export class TdAddSvg extends TypeSvgSvg {}
```

---

### 错误 2: 前缀错误

```typescript
// ❌ 错误：Common 分类使用了错误的前缀
export class XfAddSvg extends TypeSvgSvg {}

// ✅ 正确
export class TdAddSvg extends TypeSvgSvg {}
```

---

### 错误 3: 大小写错误

```typescript
// ❌ 错误
export class tdAddSvg extends TypeSvgSvg {}
export class TD_ADD_SVG extends TypeSvgSvg {}

// ✅ 正确
export class TdAddSvg extends TypeSvgSvg {}
```

---

### 错误 4: 文件名与类名不匹配

```typescript
// ❌ 错误
// 文件：my-icon.ts
export class TdMyIconSvg {} // 文件名是 my-icon，类名应该是 TdMyIconSvg

// ✅ 正确
// 文件：my-icon.ts
export class TdMyIconSvg {} // 匹配
```

## ✅ 命名检查清单

### 组件类名检查

```markdown
□ 使用正确的分类前缀（Td / El / Fl）
□ 使用 PascalCase（首字母大写）
□ 以 Svg 结尾
□ 无下划线或连字符
□ 语义清晰，易于理解
```

### 文件名检查

```markdown
□ 全部小写
□ Common/Element 使用 kebab-case（add.ts）
□ FluentUI 使用 snake_case（access_time_filled.ts）
□ .ts 扩展名
□ 与类名对应（通过转换规则）
```

### 变量名检查

```markdown
□ 使用 camelCase
□ 不使用下划线
□ 语义清晰
□ 布尔值使用 is/has/can 等前缀
```

### 方法名检查

```markdown
□ 使用 camelCase
□ 动词开头
□ 语义清晰
□ 无下划线或连字符
```
