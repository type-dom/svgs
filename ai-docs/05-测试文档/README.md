## 📊 测试覆盖率要求

### 核心指标

| 指标 | 要求 | 测量方式 |
|-----|------|---------|
| **行覆盖率** | ≥ 90% | Vitest + c8 |
| **函数覆盖率** | ≥ 95% | Vitest + c8 |
| **分支覆盖率** | ≥ 85% | Vitest + c8 |
| **语句覆盖率** | ≥ 90% | Vitest + c8 |

### 豁免情况

以下情况可申请降低覆盖率要求:

```
□ TypeScript 类型声明文件 (.d.ts)
□ 纯导出文件 (index.ts)
□ 自动生成的代码 (如 FluentUI 图标)
□ SSR 环境检测代码
□ 开发工具类代码
```

## 🧪 测试命令速查

### 基础命令

```bash
# 运行所有测试
npm test

# 监听模式运行
npm run test:watch

# 生成覆盖率报告
npm run test:coverage

# 打开 HTML 覆盖率报告
npm run test:coverage:open
```

### 特定测试

```bash
# 运行 Common 分类测试
npm run test:common

# 运行集成测试
npm run test:integration

# 运行性能测试
npm run test:perf
```

### CI/CD

```bash
# CI 环境运行
npm run test:ci

# 检查覆盖率是否达标
npm run test:check-coverage
```

## 🔍 问题排查

### 常见问题 FAQ

#### Q1: 测试失败但不知道原因？

```bash
# 查看详细错误信息
npm test -- --reporter=verbose

# 只运行单个测试文件
npm test -- tests/common/404.spec.ts

# 使用调试模式
npm run test:debug
```

#### Q2: 覆盖率不达标怎么办？

```bash
# 查看 HTML 报告找出未覆盖的代码
npm run test:coverage:open

# 使用 coverage 注释标记可忽略的代码
/* istanbul ignore next */
if (typeof window === 'undefined') {
  // SSR only code
}
```

#### Q3: 测试执行太慢？

```bash
# 使用并发执行
npm test -- --pool=forks

# 排除大型图标库测试
npm test -- --exclude='**/fluentui/**'

# 分析测试耗时
npm test -- --reporter=verbose
```

#### Q4: Mock 不工作？

```typescript
// 确保在测试前声明 Mock
vi.hoisted(() => {
  // Mock declarations
});

// 清理 Mock
afterEach(() => {
  vi.clearAllMocks();
});
```
