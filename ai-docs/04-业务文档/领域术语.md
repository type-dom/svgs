## 🔑 核心概念术语

### SVG 组件 (SVG Component)

**定义**: 基于 TypeDom 框架封装的可复用 SVG 图形元素，以 TypeScript 类形式存在。

**特征**:
- 继承自 `TypeSvgSvg` 基类
- 具有明确的 className 标识
- 包含一个或多个 SvgPath 子节点
- 支持属性配置和样式定制

**示例**:
```typescript
import { TdAddSvg } from '@type-dom/svgs';

const addIcon = new TdAddSvg({
  width: 32,
  height: 32,
  fill: 'currentColor'
});
```

**同义词**: SVG 图标、图标组件、SvgComponent

---

### TypeDom 框架 (TypeDom Framework)

**定义**: 一个基于 TypeScript 的前端 UI 框架，提供类型安全的 DOM 操作和组件系统。

**核心特性**:
- **类型安全**: 完整的 TypeScript 类型支持
- **组件化**: 基于类的组件模型
- **响应式**: 自动追踪依赖并更新
- **轻量级**: 最小运行时开销

**在@type-dom/svgs 中的角色**:
```
@type-dom/svgs
    ↓ 继承
TypeSvgSvg (来自@type-dom/framework)
    ↓ 提供
基础 DOM 能力、属性管理、生命周期
```

**相关术语**: TypeDom Components, TypeDom Ecosystem

---

### 类型安全 (Type Safety)

**定义**: 通过 TypeScript 类型系统在编译期捕获错误，确保代码正确性的机制。

**在@type-dom/svgs 中的体现**:

1. **Props 类型检查**
   ```typescript
   interface SvgProps {
     width?: number;
     height?: number;
     viewBox?: string;
     fill?: string;
   }
   
   // ✅ 类型正确
   const svg1 = new TdAddSvg({ width: 24, height: 24 });
   
   // ❌ 类型错误（编译期捕获）
   const svg2 = new TdAddSvg({ width: '24', height: 24 });
   ```

2. **继承关系验证**
   ```typescript
   class TdAddSvg extends TypeSvgSvg {
     // TypeScript 确保继承链正确
   }
   ```

3. **返回值类型标注**
   ```typescript
   resetSize(width: number, height: number): void {
     // 返回值类型明确
   }
   ```

**相关术语**: TypeScript, Static Typing, Compile-time Checking

---

### viewBox

**定义**: SVG 的视口属性，定义 SVG 图形的坐标系和缩放比例。

**格式**: `"min-x min-y width height"`

**在@type-dom/svgs 中的标准值**:
```typescript
addAttrObj(this, { viewBox: '0 0 1024 1024' });
```

**为什么使用 1024x1024**:
- ✅ **高精度**: 相比 24x24，提供更多路径细节
- ✅ **易计算**: 2 的幂次方，便于数学运算
- ✅ **标准化**: 所有图标统一坐标系
- ✅ **可缩放**: 可通过 resetSize 缩放到任意尺寸

**示例对比**:
```typescript
// 小坐标系（精度低）
viewBox: '0 0 24 24'
path: 'M10 10 L14 14'  // 只能使用整数坐标

// 大坐标系（精度高）
viewBox: '0 0 1024 1024'
path: 'M512 64C264.6 64 64 264.6 64 512...'  // 可使用小数坐标
```

**相关术语**: Coordinate System, Scaling, Aspect Ratio

## 🔧 技术术语

### Tree Shaking

**定义**: 一种构建优化技术，通过静态分析移除未使用的代码，减小打包体积。

**在@type-dom/svgs 中的实现**:

1. **ESM 模块格式**
   ```typescript
   // ✅ 支持 tree-shaking
   export { TdAddSvg } from './lib/common/TdAddSvg';
   
   // ❌ 不支持 tree-shaking
   module.exports = { TdAddSvg };
   ```

2. **独立导出**
   ```typescript
   // 按需导入，只打包使用的图标
   import { TdAddSvg } from '@type-dom/svgs';
   // TdCloseSvg 不会被打包
   
   // vs 全量导入
   import * as AllSvgs from '@type-dom/svgs';
   // 所有图标都会被打包
   ```

**效果对比**:
```
不使用 tree-shaking: ~500KB (全部图标)
使用 tree-shaking:   ~5KB (单个图标)
优化比例：99%
```

**相关术语**: Dead Code Elimination, Bundle Optimization, ESM

### Unbundle Mode

**定义**: Vite 的一种构建模式，保持源代码结构，不进行预打包。

**优势**:
- ✅ **保持源码结构**: 每个组件独立文件
- ✅ **快速开发**: 无需等待打包
- ✅ **精确调试**: 直接定位到源文件
- ✅ **按需加载**: 浏览器只请求需要的文件

**在@type-dom/svgs 中的应用**:

```typescript
// tsdown.config.ts (unbundle mode)
export default {
  entry: ['src/index.ts'],
  format: ['esm'],
  // 保持目录结构
  outDir: 'dist/lib/'
};
```

**输出结构**:
```
dist/
├── lib/
│   ├── common/
│   │   ├── TdAddSvg.mjs
│   │   └── TdAddSvg.d.mts
│   ├── element-plus/
│   │   └── ...
│   └── fluentui/
│       └── ...
└── index.mjs
```

**相关术语**: Vite, Esbuild, Development Build

### SvgPath

**定义**: TypeDom 框架中用于表示 SVG `<path>` 元素的类。

**属性**:
```typescript
interface SvgPathOptions {
  d: string;      // 路径数据 (必需)
  fill?: string;  // 填充颜色
  stroke?: string;// 描边颜色
  strokeWidth?: number;
}
```

**使用示例**:
```typescript
import { SvgPath } from '@type-dom/framework';

const path = new SvgPath({
  d: 'M512 64C264.6 64 64 264.6 64 512s200.6 448 448 448 448-200.6 448-448S759.4 64 512 64z',
  fill: '#C9C9C9'
});
```

**与 SVGPathElement 的区别**:
- `SvgPath`: TypeDom 封装的类，用于组件内部
- `SVGPathElement`: 浏览器原生的 DOM 接口

**相关术语**: Path Data, Canvas Rendering

### addAttrObj

**定义**: TypeDom 框架提供的工具函数，用于批量添加 SVG 属性。

**签名**:
```typescript
function addAttrObj(
  target: TypeSvgSvg,
  attrs: Record<string, any>
): void;
```

**使用示例**:
```typescript
import { addAttrObj } from '@type-dom/framework';

export class TdAddSvg extends TypeSvgSvg {
  constructor(params: SvgProps = {}) {
    super(params);
    
    // 批量添加属性
    addAttrObj(this, {
      name: 'TdAddSvg',
      viewBox: '0 0 1024 1024',
      class: 'icon-add'
    });
  }
}
```

**等价的原生写法**:
```typescript
// 逐个添加（繁琐）
this.setAttr('name', 'TdAddSvg');
this.setAttr('viewBox', '0 0 1024 1024');
this.setAttr('class', 'icon-add');

// 使用 addAttrObj（简洁）
addAttrObj(this, {
  name: 'TdAddSvg',
  viewBox: '0 0 1024 1024',
  class: 'icon-add'
});
```

**相关术语**: Attribute Management, Batch Operations

## 📦 构建与发布术语

### Semantic Versioning (语义化版本)

**定义**: 版本号格式为 `X.Y.Z` (主版本号。次版本号。修订号)。

**规则**:
- **X (MAJOR)**: 不兼容的变更
  - 删除现有图标
  - 修改 API 接口
  - 破坏性更新

- **Y (MINOR)**: 向后兼容的功能新增
  - 新增图标分类
  - 增加新组件
  - 功能增强

- **Z (PATCH)**: 向后兼容的问题修复
  - 修复 bug
  - 性能优化
  - 文档更新

**示例**:
```
v0.4.0 → v0.4.1  # PATCH: 修复问题
v0.4.1 → v0.5.0  # MINOR: 新增图标
v0.5.0 → v1.0.0  # MAJOR: 重大变更
```

**在@type-dom/svgs 中的应用**:
```json
{
  "name": "@type-dom/svgs",
  "version": "0.4.0"
}
```

**相关术语**: Release Management, Changelog

## 🧪 测试术语

### Unit Test (单元测试)

**定义**: 对最小可测试单元（通常是函数或类）进行的隔离测试。

**在@type-dom/svgs 中的测试对象**:
- SVG 组件构造函数
- resetSize 方法
- addChild/removeChild方法
- mount/unmount方法

**示例**:
```typescript
describe('TdAddSvg Unit Tests', () => {
  it('should create instance with correct className', () => {
    const svg = new TdAddSvg();
    expect(svg.className).toBe('TdAddSvg');
  });
  
  it('should have child nodes', () => {
    const svg = new TdAddSvg();
    expect(svg.childNodes.length).toBeGreaterThan(0);
  });
  
  it('should reset size correctly', () => {
    const svg = new TdAddSvg();
    svg.resetSize(32, 32);
    expect(svg.width).toBe(32);
    expect(svg.height).toBe(32);
  });
});
```

**测试工具**: Vitest

**相关术语**: Test Coverage, Mock, Stub

```typescript
describe('SVG Integration Tests', () => {
```

## 📚 其他重要术语

### currentColor

**定义**: CSS 关键字，表示当前元素的 text-color 值。

**在 SVG 中的应用**:
```xml
<!-- SVG 使用 currentColor -->
<path fill="currentColor" d="..."/>
```

**TypeScript 中的使用**:
```typescript
new SvgPath({
  d: '...',
  fill: 'currentColor'  // 继承父元素的 color 样式
```

**CSS 控制**:
```css
.icon-container {
  color: #333;  /* SVG 会继承这个颜色 */
```

**优势**:
- ✅ **主题一致**: 图标颜色与文字颜色同步
- ✅ **易于维护**: 只需修改一处 color
- ✅ **响应式**: 可根据状态自动变色

**相关术语**: CSS Inheritance, Theming

### Pixelmatch

**定义**: 一个轻量级的像素级图像对比库，用于视觉回归测试。

**用途**: 检测 SVG 渲染后的视觉差异。

**使用示例**:
```typescript
import pixelmatch from 'pixelmatch';

function compareSvgRendering(
  img1: ImageData,
  img2: ImageData
): number {
  const diff = new ImageData(img1.width, img1.height);
  const mismatch = pixelmatch(
    img1.data,
    img2.data,
    diff.data,
    img1.width,
    img2.height,
    { threshold: 0.1 }
  );
  
  return mismatch;  // 返回差异像素数
}
```

**在@type-dom/svgs 中的应用**:
- 对比不同版本的 SVG 渲染
- 验证重构后的视觉效果
- 跨浏览器一致性检查

**相关术语**: Visual Regression, Screenshot Testing
