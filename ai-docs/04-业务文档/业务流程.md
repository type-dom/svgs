## 🔍 流程一：需求分析与分类

### 1.1 图标来源识别

#### Common 分类图标

**特点**: TypeDom 通用图标，简洁基础
**前缀**: `Td`
**数量**: ~195 个

**典型场景**:
- ✅ 基础操作：添加、删除、编辑、保存
- ✅ 导航元素：箭头、菜单、首页
- ✅ 状态标识：成功、失败、警告、信息
- ✅ 常用对象：用户、设置、搜索、通知

**示例**:
```typescript
TdAddSvg          // 添加
TdCloseSvg        // 关闭
TdUserSvg         // 用户
TdSearchSvg       // 搜索
```

#### Element Plus 分类图标

**特点**: Element Plus UI 风格，现代化设计
**前缀**: `El`
**数量**: ~293 个

**典型场景**:
- ✅ UI 控件：下拉、上传、切换
- ✅ 数据展示：表格、图表、列表
- ✅ 表单元素：日期、时间、选择器
- ✅ 品牌标识：各大平台 logo

**示例**:
```typescript
ElArrowDownSvg    // 下箭头
ElUploadSvg       // 上传
ElDateSvg         // 日期
ElWechatSvg       // 微信
```

#### FluentUI 分类图标

**特点**: Microsoft Fluent UI 设计语言，丰富多样
**前缀**: `Fl`
**数量**: ~5,255 个

**典型场景**:
- ✅ 办公应用：文档、表格、演示文稿
- ✅ 人员协作：团队、聊天、会议
- ✅ 云服务：OneDrive、SharePoint、Teams
- ✅ 系统功能：设置、权限、安全

**风格变体**:
- `Regular`: 常规线框风格
- `Filled`: 填充风格
- `Color`: 彩色版本

**示例**:
```typescript
FlAccessTimeSvg        // 时间（常规）
FlAccessTimeFilledSvg  // 时间（填充）
FlMicrosoftTeamsSvg    // Teams
```

### 2.2 SVG 文件预处理

#### 标准化检查清单

- [ ] **viewBox 统一为 `0 0 1024 1024`**
  ```xml
  <!-- ❌ 原始 -->
  <svg viewBox="0 0 24 24">
  
  <!-- ✅ 标准化 -->
  <svg viewBox="0 0 1024 1024">
  ```

- [ ] **移除不必要的元素**
  ```xml
  <!-- 移除 -->
  <defs>...</defs>
  <style>...</style>
  <?xml version="1.0" encoding="UTF-8"?>
  ```

- [ ] **简化路径数据**
  ```xml
  <!-- ❌ 冗余精度 -->
  <path d="M10.123456 20.789012 L30.456789 40.123456"/>
  
  <!-- ✅ 合理精度 -->
  <path d="M10.12 20.79 L30.46 40.12"/>
  ```

- [ ] **统一颜色值**
  ```xml
  <!-- 使用currentColor或具体色值 -->
  <path fill="currentColor"/>
  <path fill="#C9C9C9"/>
  ```

### 3.2 转换脚本工作原理

#### 核心转换逻辑

```typescript
// trans-svgs/utils.mjs
import { readFileSync, writeFileSync } from 'fs';
import { parse } from 'node-html-parser';

export function convertSvgToTypeScript(svgPath: string): string {
  // 1. 读取 SVG 文件
  const svgContent = readFileSync(svgPath, 'utf-8');
  
  // 2. 解析 SVG
  const root = parse(svgContent);
  const svgElement = root.querySelector('svg');
  
  // 3. 提取属性
  const viewBox = svgElement.getAttribute('viewBox') || '0 0 1024 1024';
  const paths = svgElement.querySelectorAll('path');
  
  // 4. 生成 TypeScript 类
  const className = generateClassName(svgPath);
  const pathData = paths.map(path => ({
    d: path.getAttribute('d'),
    fill: path.getAttribute('fill') || 'currentColor'
  }));
  
  return generateTypeScriptClass(className, viewBox, pathData);
}

function generateTypeScriptClass(
  className: string,
  viewBox: string,
  paths: Array<{ d: string; fill: string }>
): string {
  return `
import { TypeSvgSvg } from '@type-dom/framework';
import { SvgPath, SvgProps, addAttrObj } from '@type-dom/framework';

export class ${className} extends TypeSvgSvg {
  className: '${className}';
  override childNodes: SvgPath[];
  
  constructor(params: SvgProps = {}) {
    super(params);
    this.className = '${className}';
    addAttrObj(this, { name: '${className}' });
    addAttrObj(this, { viewBox: '${viewBox}' });
    this.resetSize(24, 24);
    
    this.childNodes = [
      ${paths.map(p => `new SvgPath({ d: '${p.d}', fill: '${p.fill}' })`).join(',\n      ')}
    ];
  }
}
  `.trim();
}
```

## 🚀 流程七：发布上线

### 7.1 版本管理

#### 版本号规则

遵循语义化版本 (SemVer): `MAJOR.MINOR.PATCH`

- **MAJOR**: 不兼容的变更
  - 删除现有图标
  - 修改 API 接口
  - 改变继承关系

- **MINOR**: 向后兼容的功能
  - 新增图标分类
  - 增加新的工具函数
  - 扩展配置选项

- **PATCH**: 向后兼容的问题修复
  - 修复图标路径错误
  - 修正类型定义
  - 性能优化

#### 发布检查清单

```bash
# 1. 更新版本号
npm version patch  # 或 minor, major

# 2. 运行完整测试
npm run test
npm run typecheck
npm run build

# 3. 查看变更
git diff

# 4. 提交并推送
git commit -am "chore: release v0.4.1"
git push origin main

# 5. 发布到 NPM
npm publish --access public
```

### 7.2 发布后验证

#### NPM 包验证
