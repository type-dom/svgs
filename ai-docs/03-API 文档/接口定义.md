## 📋 组件接口总览

### SVG 组件通用接口

所有 SVG 组件都实现以下接口:

```typescript
interface SvgComponent {
  // 属性
  className: string; // 组件类名
  childNodes: SvgPath[]; // 子节点数组
  attrObj: Record<string, any>; // SVG 属性对象
  styleObj: Record<string, any>; // 样式对象

  // 方法
  constructor(params?: SvgProps): this; // 构造函数
  resetSize(width: number, height: number): void; // 重置尺寸
  addChild(...children: TypeElement[]): void; // 添加子节点
  removeChild(child: TypeElement): void; // 移除子节点
  setAttr(key: string, value: any): void; // 设置属性
  setStyle(key: string, value: string): void; // 设置样式
  mount(container: HTMLElement): void; // 挂载到 DOM
}
```

## 🔧 核心接口详解

### 1. SvgProps 接口

SVG 组件构造函数的参数类型定义:

```typescript
interface SvgProps {
  // ========== 基础属性 ==========
  /**
   * SVG 宽度（像素或百分比）
   * @example 24, "100%", "2em"
   */
  width?: number | string;

  /**
   * SVG 高度（像素或百分比）
   * @example 24, "100%", "2em"
   */
  height?: number | string;

  /**
   * viewBox 属性，定义 SVG 的可视区域
   * @default "0 0 1024 1024"
   */
  viewBox?: string;

  // ========== 样式属性 ==========
  /**
   * 填充颜色
   * @default "currentColor" - 继承父元素颜色
   * @example "#333", "red", "currentColor"
   */
  fill?: string;

  /**
   * 描边颜色
   * @example "#000", "transparent"
   */
  stroke?: string;

  /**
   * 描边宽度
   * @example 1, 2, "1.5px"
   */
  strokeWidth?: number | string;

  /**
   * 透明度 (0-1)
   * @default 1
   */
  opacity?: number;

  // ========== 事件处理 ==========
  /**
   * 点击事件处理器
   */
  onClick?: (event: MouseEvent) => void;

  /**
   * 鼠标移入事件处理器
   */
  onMouseEnter?: (event: MouseEvent) => void;

  /**
   * 鼠标移出事件处理器
   */
  onMouseLeave?: (event: MouseEvent) => void;

  /**
   * 鼠标按下事件处理器
   */
  onMouseDown?: (event: MouseEvent) => void;

  /**
   * 鼠标松开事件处理器
   */
  onMouseUp?: (event: MouseEvent) => void;

  // ========== 其他 SVG 属性 ==========
  /**
   * 保持宽高比
   * @default "xMidYMid meet"
   */
  preserveAspectRatio?: string;

  /**
   * XML 命名空间
   * @default "http://www.w3.org/2000/svg"
   */
  xmlns?: string;

  /**
   * 唯一标识符
   */
  id?: string;

  /**
   * CSS 类名
   */
  class?: string;

  /**
   * 内联样式
   */
  style?: string;

  /**
   * 标题（用于无障碍访问）
   */
  title?: string;

  /**
   * 描述文本（用于无障碍访问）
   */
  desc?: string;
}
```

### 2. TypeProps 接口

TypeDom 通用组件属性接口:

```typescript
interface TypeProps {
  /**
   * 组件类名（用于类型识别）
   */
  className?: string;

  /**
   * DOM 元素 ID
   */
  id?: string;

  /**
   * HTML 属性对象
   * @example { role: "img", "aria-label": "Add icon" }
   */
  attrObj?: Record<string, any>;

  /**
   * CSS 样式对象
   * @example { display: "block", margin: "10px" }
   */
  styleObj?: Record<string, any>;

  /**
   * 子组件数组
   */
  children?: TypeElement[];

  /**
   * 事件处理器对象
   * @example { onClick: handler, onMouseEnter: handler }
   */
  events?: Record<string, Function>;

  /**
   * 引用（用于访问组件实例）
   */
  ref?: any;
}
```

### 组合使用

```typescript
import { Division, Text, TypeRoot } from "@type-dom/framework";
import { TdAddSvg } from "@type-dom/svgs/common/add";

export class ButtonWithIcon extends TypeRoot {
  className: "ButtonWithIcon";

  constructor() {
    super();
    this.className = "ButtonWithIcon";

    // ✅ 图标 + 文字组合
    const button = new Division({
      attrObj: {
        class: "btn",
        role: "button",
        tabindex: "0",
      },
      styleObj: {
        display: "flex",
        alignItems: "center",
        gap: "8px",
        padding: "8px 16px",
        cursor: "pointer",
      },
      children: [
        new TdAddSvg({
          width: 16,
          height: 16,
          fill: "currentColor",
        }),
        new Text({ text: "Add Item" }),
      ],
      events: {
        click: () => this.handleClick(),
      },
    });

    this.addChild(button);
  }

  handleClick() {
    console.log("Button clicked");
  }
}
```

## 🔍 属性验证

### 运行时验证

```typescript
class ValidatedSvgComponent extends TypeSvgSvg {
  constructor(params: SvgProps = {}) {
    super(params);

    // 验证必填属性
    if (!params.viewBox) {
      params.viewBox = "0 0 1024 1024";
    }

    // 验证尺寸范围
    if (typeof params.width === "number") {
      if (params.width < 0 || params.width > 1000) {
        console.warn("Width should be between 0 and 1000");
      }
    }

    // 验证颜色格式
    if (params.fill && !this.isValidColor(params.fill)) {
      console.warn("Invalid color format:", params.fill);
    }
  }

  private isValidColor(color: string): boolean {
    // 简单的颜色验证逻辑
    return (
      /^#?[0-9a-fA-F]{3,8}$/.test(color) || /^(rgb|hsl)a?\(/.test(color) || /^[a-z]+$/i.test(color)
    );
  }
}
```

| 接口             | 用途             | 主要属性                               | 使用场景              |
| ---------------- | ---------------- | -------------------------------------- | --------------------- |

## 🎯 最佳实践

### 1. 使用 currentColor

```typescript
// ✅ 推荐：主题友好
new TdAddSvg({ fill: "currentColor" });

// ❌ 避免：硬编码颜色
new TdAddSvg({ fill: "#333333" });
```

---

### 2. 提供合理的默认值

```typescript
export class TdAddSvg extends TypeSvgSvg {
  constructor(params: SvgProps = {}) {
    super(params);

    // 设置合理的默认值
    this.resetSize(24, 24); // 默认 24x24
    addAttrObj(this, {
      viewBox: "0 0 1024 1024", // 标准 viewBox
      fill: "currentColor", // 继承颜色
    });
  }
}
```

## ❓ 常见问题

### Q1: 如何动态修改 SVG 属性？

**A**: 使用 `setAttr` 方法:

```typescript
const icon = new TdAddSvg();

// 修改 viewBox
icon.setAttr("viewBox", "0 0 512 512");

// 修改填充色
icon.setAttr("fill", "#ff0000");

// 批量修改
icon.setAttrs({
  width: 32,
  height: 32,
  fill: "blue",
});
```

---

### Q2: 如何获取 SVG 组件的属性？

**A**: 直接访问 `attrObj`:

```typescript
const icon = new TdAddSvg();

// 获取单个属性
const viewBox = icon.attrObj.viewBox;

// 获取所有属性
console.log(icon.attrObj);
```

---

### Q3: 如何在运行时改变尺寸？

**A**: 使用 `resetSize` 方法:

```typescript
const icon = new TdAddSvg();

// 初始尺寸 24x24
icon.resetSize(24, 24);

// 动态改为 48x48
icon.resetSize(48, 48);

// 改为响应式
icon.setAttr("width", "100%");
icon.setAttr("height", "auto");
```

---

### Q4: 如何添加自定义数据属性？

**A**: 在 `attrObj` 中添加:

```typescript
new TdAddSvg({
  attrObj: {
    "data-id": "add-icon-123",
    "data-action": "add",
    "data-category": "main-actions",
  },
});
```
