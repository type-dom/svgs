## 🔴 类型错误 (Type Errors)

### TDSVG001 - Props 类型不匹配

**错误代码**: `TDSVG001`  
**严重程度**: ⚠️ Error  
**触发场景**: 传递给 SVG 组件的 props 类型与定义不符

#### 错误示例

```typescript
// ❌ 错误：width 应该是 number 类型
const svg = new TdAddSvg({
  width: '24',  // Type 'string' is not assignable to type 'number'
  height: 24
});

// ❌ 错误：viewBox 应该是字符串
const svg = new TdAddSvg({
  viewBox: ['0', '0', '1024', '1024']  // Type 'string[]' is not assignable
});
```

#### 正确用法

```typescript
// ✅ 正确
const svg = new TdAddSvg({
  width: 24,
  height: 24,
  viewBox: '0 0 1024 1024'
});
```

#### 解决方案

1. **检查 Props 类型定义**
   ```typescript
   interface SvgProps {
     width?: number;
     height?: number;
     viewBox?: string;
     // ...
   }
   ```

2. **使用 TypeScript 严格模式**
   ```json
   {
     "compilerOptions": {
       "strict": true
     }
   }
   ```

### TDSVG002 - 必需属性缺失

**错误代码**: `TDSVG002`  
**严重程度**: ⚠️ Error  
**触发场景**: 未提供必需的 SVG 属性

#### 错误示例

```typescript
// ❌ 错误：缺少 viewBox 属性
export class TdAddSvg extends TypeSvgSvg {
  constructor(params: SvgProps = {}) {
    super(params);
    // viewBox 未设置，可能导致渲染问题
  }
}
```

#### 正确用法

```typescript
// ✅ 正确：始终设置 viewBox
export class TdAddSvg extends TypeSvgSvg {
  constructor(params: SvgProps = {}) {
    super(params);
    addAttrObj(this, { viewBox: '0 0 1024 1024' });
  }
}
```

### TDSVG003 - className 命名冲突

**错误代码**: `TDSVG003`  
**严重程度**: ⚠️ Warning  
**触发场景**: className 与现有类名重复

#### 错误示例

```typescript
// ❌ 错误：className 不符合命名规范
export class TdAddSvg extends TypeSvgSvg {
  className: 'AddSvg';  // 缺少 Td 前缀
}
```

#### 正确用法

```typescript
// ✅ 正确：遵循命名规范
export class TdAddSvg extends TypeSvgSvg {
  className: 'TdAddSvg';  // Td + Add + Svg
}
```

## 🟡 运行时错误 (Runtime Errors)

### TDSVG101 - 初始化失败

**错误代码**: `TDSVG101`  
**错误信息**: `Failed to initialize SVG component: {componentName}`  
**严重程度**: 🔴 Critical  
**触发场景**: SVG 组件构造函数执行失败

#### 常见原因

1. **父类构造函数调用失败**
   ```typescript
   // ❌ 可能导致错误
   export class TdAddSvg extends TypeSvgSvg {
     constructor(params: SvgProps) {
       // 忘记调用 super(params)
       this.className = 'TdAddSvg';
     }
   }
   ```

2. **TypeDom 框架未正确加载**
   ```bash
   Error: TypeSvgSvg is not defined
   ```

#### 解决方案

```typescript
// ✅ 正确模式
export class TdAddSvg extends TypeSvgSvg {
  className: 'TdAddSvg';
  override childNodes: SvgPath[];
  
  constructor(params: SvgProps = {}) {
    super(params);  // 必须先调用父类构造函数
    
    // 初始化属性
    addAttrObj(this, { name: 'TdAddSvg' });
    addAttrObj(this, { viewBox: '0 0 1024 1024' });
    
    // 设置默认尺寸
    this.resetSize(24, 24);
    
    // 创建路径
    this.childNodes = [
      new SvgPath({ d: 'M512 64C264.6 64 64 264.6 64 512s200.6 448 448 448 448-200.6 448-448S759.4 64 512 64z', fill: '#C9C9C9' }),
      // ... more paths
    ];
  }
}
```

**严重程度**: 🟠 High  
**触发场景**: resetSize() 方法接收到无效参数

#### 错误示例

```typescript
// ❌ 错误：传递负数
svg.resetSize(-24, 24);

// ❌ 错误：传递 0
svg.resetSize(0, 0);

// ❌ 错误：传递非数字
svg.resetSize('24' as any, 24);
```

```typescript
// ✅ 正确：正整数
svg.resetSize(24, 24);
svg.resetSize(32, 32);
svg.resetSize(64, 64);

// ✅ 带验证的实现
resetSize(width: number, height: number): void {
  if (width <= 0 || height <= 0) {
    throw new Error('Width and height must be positive numbers');
  }
  // ... implementation
}
```

### TDSVG103 - 子节点添加失败

**错误代码**: `TDSVG103`  
**错误信息**: `Failed to add child node: invalid TypeElement`  
**严重程度**: 🟠 High  
**触发场景**: addChild() 接收到无效的子节点

#### 错误示例

```typescript
// ❌ 错误：添加非 TypeElement 对象
svg.addChild({ d: 'M512 64...' });  // 应该是 SvgPath 实例

// ❌ 错误：添加 null/undefined
svg.addChild(null);
svg.addChild(undefined);
```

#### 正确用法

```typescript
// ✅ 正确：添加 SvgPath 实例
svg.addChild(
  new SvgPath({ 
    d: 'M512 64C264.6 64 64 264.6 64 512s200.6 448 448 448 448-200.6 448-448S759.4 64 512 64z',
    fill: '#C9C9C9'
  })
);

// ✅ 正确：批量添加
svg.childNodes = [
  new SvgPath({ d: '...', fill: '#C9C9C9' }),
  new SvgPath({ d: '...', fill: '#FFFFFF' })
];
```

## 🔵 构建错误 (Build Errors)

### TDSVG201 - TypeScript 编译错误

**错误代码**: `TDSVG201`  
**严重程度**: 🔴 Critical  
**触发场景**: TypeScript 编译器报错

#### 常见错误及解决方案

**1. 类型不兼容**

```bash
error TS2416: Property 'childNodes' in type 'TdAddSvg' 
is not assignable to the same property in base type 'TypeSvgSvg'.
```

**解决方案**:
```typescript
// ✅ 使用 override 关键字
export class TdAddSvg extends TypeSvgSvg {
  override childNodes: SvgPath[];  // 明确标注 override
  
  constructor(params: SvgProps = {}) {
    super(params);
    this.childNodes = [/* ... */];
  }
}
```

**2. 模块解析失败**

```bash
error TS2307: Cannot find module '@type-dom/framework' or its corresponding type declarations.
```

**解决方案**:
```bash
# 安装依赖
npm install @type-dom/framework

# 或检查 tsconfig.json
{
  "compilerOptions": {
    "moduleResolution": "bundler",
    "paths": {
      "@type-dom/framework": ["./node_modules/@type-dom/framework"]
    }
  }
}
```

### TDSVG202 - 类型声明文件生成失败

**错误代码**: `TDSVG202`  
**严重程度**: 🟠 High  
**触发场景**: .d.ts 文件生成时出错

#### 常见原因

1. **导出语句不完整**
   ```typescript
   // ❌ 可能的问题：缺少显式导出
   class TdAddSvg extends TypeSvgSvg { }
   
   // ✅ 应该显式导出
   export class TdAddSvg extends TypeSvgSvg { }
   ```

2. **循环依赖**
   ```typescript
   // file-a.ts
   import { FileB } from './file-b';  // 循环
   
   // file-b.ts
   import { FileA } from './file-a';  // 循环
   ```

#### 解决方案

```typescript
// ✅ 重构避免循环依赖
// common-types.ts
export interface SvgPath { /* ... */ }

// file-a.ts
import { SvgPath } from './common-types';

// file-b.ts
import { SvgPath } from './common-types';
```

```typescript
export class TdAddSvg extends TypeSvgSvg {
```

## 📊 错误处理最佳实践

### 1. 防御性编程

```typescript
export class TdAddSvg extends TypeSvgSvg {
  constructor(params: SvgProps = {}) {
    super(params);
    
    // 验证参数
    if (params.width && params.width <= 0) {
      console.warn('Width should be positive, using default 24');
      this.resetSize(24, 24);
    } else {
      this.resetSize(params.width || 24, params.height || 24);
    }
    
    // 验证 childNodes
    if (!this.childNodes || this.childNodes.length === 0) {
      throw new Error('TdAddSvg must have at least one child path');
    }
  }
}
```

### 2. 错误日志记录

```typescript
interface SvgError {
  code: string;
  message: string;
  component: string;
  timestamp: Date;
  details?: Record<string, any>;
}

function logSvgError(error: SvgError): void {
  console.error(`[${error.code}] ${error.component}: ${error.message}`, {
    timestamp: error.timestamp,
    details: error.details
  });
}
```

### 3. 单元测试覆盖

```typescript
describe('TdAddSvg Error Handling', () => {
```
